# Monitor_iot
Humidity, Temperature and Light intensity monitor with MQTT IoT features and a Node-RED front-end.
Built with ESP-32 compatibility in mind.

! WIP ! This readme is currently being written. !

Libraries used: 
* Adafruit_GFX
* Adafruit_SSD1306
* PubSubClient
* DHT.h (By Adafruit)
